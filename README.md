# Yaser Alyousfi — GitHub Pages export

This folder is a complete static export of the executive profile website.

## Publish on GitHub Pages

1. Upload every file and folder here to the root of a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Select **Deploy from a branch**, choose the branch containing these files, and select **/(root)**.
4. Save and wait for GitHub Pages to provide the public URL.

All site assets use relative paths, so the website works from a project subpath as well as a custom domain. No Next.js server, chatgpt.site runtime, JavaScript framework, external webfont, or build step is required. The original site uses system font stacks and native anchor navigation.
